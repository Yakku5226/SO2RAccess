Using your own sounds
---------------------

To replace any cue, put a WAV of the same name in:

    UserData\SO2RAccess\Sounds

inside the game folder. A file there is used instead of the bundled copy and
survives mod updates. The file names are:

    Dodge.wav          dodge warning
    Jump.wav           jump prompt
    Save_sound.wav     game saved
    PrivateAction.wav  private action available
    GaugeFill.wav      bonus gauge filled
    Enemynearby.wav    enemy proximity loop
    bubble_big.wav     fishing spot reached
    Wall_front.wav     wall ahead (loop)
    Wall_right.wav     wall to the right (loop)
    Wall_behind.wav    wall behind (loop)
    Wall_left.wav      wall to the left (loop)
    NavNpc.wav         NPC beacon (loop)
    NavChest.wav       unopened chest beacon (loop)
    NavDoor.wav        door / exit beacon (loop)
    NavLocation.wav    location and warp beacon (loop)
    NavSave.wav        save point beacon (loop)
    NavJump.wav        jump-down ledge beacon (loop)
    NavStairs.wav      stairs and ladder beacon (loop) — NOT bundled; drop
                       your own file here to give stairs a sound
    NavBump.wav        wall bump (one short hit) — NOT bundled and not yet in
                       the menu; reserved for a future release

The looping cues are played end to end, so a seamless loop file sounds best.

Cues must be integer PCM WAV files — 16-bit is recommended, and volume
control in the mod settings menu only applies to 8-bit and 16-bit audio.
32-bit float WAVs will not play.
