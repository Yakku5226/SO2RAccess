Using your own sounds
---------------------

To replace any cue, put a WAV of the same name in:

    UserData\SO2RAccess\Sounds

inside the game folder. A file there is used instead of the bundled copy and
survives mod updates. The file names are:

    Dodge.wav          dodge warning
    Jump.wav           jump prompt
    Save_sound.wav     game saved
    PrivateAction.wav  private action available
    GaugeFill.wav      bonus gauge filled
    Enemynearby.wav    enemy proximity loop
    bubble_big.wav     fishing spot reached

Cues must be integer PCM WAV files — 16-bit is recommended, and volume
control in the mod settings menu only applies to 8-bit and 16-bit audio.
32-bit float WAVs will not play.
